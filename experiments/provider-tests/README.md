# Provider Tests

这个目录用于存放外部模型 Provider 的测试脚本和结果图，主要服务于模型选型与效果对比。

当前包含的内容主要有：

- `krea_*`
  - Krea 相关测试脚本与输出图

- `zimage_*`
  - Tongyi / Z-Image 路线测试脚本与输出图

- `tongyi_xianxia_test.py`
  - 古风仙侠主题测试脚本


这些脚本不属于主系统运行必需文件，它们的作用是：

1. 记录不同模型的调用方式
2. 对比不同 Prompt 写法带来的效果差异
3. 给主系统后续的模型接入提供参考

主系统的运行入口仍然是：

- `../../app.py`
